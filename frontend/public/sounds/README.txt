Folder ini digunakan untuk menyimpan file audio notifikasi aplikasi OSCE.

File Audio Broadcast Default:
- Path: /public/sounds/broadcast.mp3
- Keterangan: Jika Anda ingin mengganti suara broadcast notifikasi dengan file MP3 milik Anda sendiri, letakkan file audio dengan nama `broadcast.mp3` di folder ini (`frontend/public/sounds/broadcast.mp3`).

Sistem juga dilengkapi dengan Web Audio API Synthesizer bawaan yang otomatis menghasilkan suara lonceng chime jernih (2-tone bell) tanpa ketergantungan file eksternal.
